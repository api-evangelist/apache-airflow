# Apache Airflow

> Apache Airflow is an open-source platform to programmatically author, schedule, and monitor workflows, developed by the Apache Software Foundation. Workflows are defined as Directed Acyclic Graphs (DAGs) in Python. Airflow ships a stable REST API for managing DAGs, DAG runs, task instances, connections, variables, pools, roles, users, datasets, and monitoring resources. It is self-hosted; there is no single vendor endpoint (the OpenAPI servers are deployment-relative, e.g. /api/v1).

This llms.txt was generated by API Evangelist from the catalog entry (apis.yml) and repo artifacts; Apache Airflow does not publish its own llms.txt.

## APIs

- [Apache Airflow REST API (stable)](https://airflow.apache.org/docs/apache-airflow/stable/stable-rest-api-ref.html): Stable REST API — DAGs, DAG runs, task instances, connections, variables, pools, roles, users, datasets, monitoring. Base path /api/v1 (v2.x) or /api/v2 (3.x).
- [Experimental API (deprecated)](https://airflow.apache.org/docs/apache-airflow/stable/deprecated-rest-api-ref.html): Legacy /api/experimental — do not use for new work.
