# Apache Airflow (apache-airflow)
Apache Airflow is an open-source platform to programmatically author, schedule, and monitor workflows. It allows you to define workflows as code, making them maintainable, versionable, testable, and collaborative.

**URL:** [Visit APIs.json URL](https://airflow.apache.org/)

## APIs

### Apache Airflow REST API
The stable public REST API for interacting with Apache Airflow programmatically, allowing management of DAGs, tasks, connections, and more.
